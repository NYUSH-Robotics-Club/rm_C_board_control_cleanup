# Yaw 目标与制动改进方案

2026-09-11：依据 yaw-20260911-after-queue 实机记录提出。目标生成与连续角度已实施并构建，尚未烧录；提前制动及积分策略仍是待办。
目标是消除控制频率影响、回中提速和跨半圈重选方向，并改善速度环制动。
当前前向参考4555刻度只作坐标参考；不得据此自动上电回正。

## 已实施范围与速度调试入口

- 步兵`config/robots/infantry_standard.c`的`s_yaw_control.speed_loop_only=true`暂时旁路位置PID，
  普通遥控满杆30°/s转换为±5 RPM，回中目标0 RPM。视觉/spin下yaw速度目标为0且仅使用电机RPM反馈，
  不让这些模式的位置误差介入内环调试；底盘模式不受这个开关控制。
- 目标按实际dt积分，推杆新目标领先限10°、回中冻结；正常位置路径普通限10 RPM，视觉/spin分别配置。
  内环用户参数3.3/3.3/.825及电流协议5460保持。未实施上方建议的清I/D、制动规划或抗饱和改造。
- 连续状态由`application/gimbal/yaw_reference.c`维护；单圈`angle_target`语义保留。
  控制/反馈间隔超过20ms、反馈越界或超出跟踪范围时作废，双轴归零，重新等待稳定反馈并锁当前位置。
  跟踪范围采用500 RPM及相邻位移包络作为软件有效性约束，不是电机额定/机械最大值，也不能证明
  任意外力导致的整圈跳变都可被检测。正常跟踪依赖相邻反馈实际位移小于半圈。
- 手动/视觉/spin显式选择模式，spin进入时选择一次世界航向圈数；模式切换以当前测量初始化D历史。
  哨兵保持位置环及原普通300/视觉500/spin500 RPM限速，旧70刻度以200Hz参考换算615.234375°/s，
  领先量180°；该换算基准不是哨兵实测频率，新行为需上板确认。
- `speed_loop_only=false`可恢复位置环，需重新构建烧录；恢复时仍应先完成低速内环调参，当前外环P=1未代改。
- 完整GCC主机回归通过，包含时间积分、领先限制、冻结目标、多圈误差、速度旁路、模式切换及失联重对齐。
  `just build`与`just build sentry_swerve`通过，冻结底层未编辑；本次无硬件操作。

## 目标与坐标

- 手动目标按真实秒单位时间积分：Δtarget_ticks = stick × max_rate_deg_s × dt_s × 8192/360。
  第一版低速验证候选满杆30°/s，普通模式推杆/回中统一限10 RPM（60°/s）；这些不是已验证稳定参数。
- 输入先经死区与回中滞回；推杆时限制新目标的领先量，候选10°。已有误差超界时仅允许
  减少误差的输入，禁止继续向外累加。回中冻结目标，不能每周期裁剪到当前位置附近而拖动锁位目标。
- yaw应用状态维护连续编码器角度与同一坐标系的连续目标。新反馈增量用wrap(raw-last_raw)，
  但位置控制误差直接用target_continuous-position_continuous，不再每轮wrap目标误差。
  显示及外部单圈角使用0..8191；兼容字段angle_target保留单圈语义，不能直接改它而影响其他消费者。
- 单圈绝对目标（未来如4555回正）只在接收命令时选择一次对应圈数，执行途中不重新选择。
  模式切换需显式初始化坐标/目标与控制状态，视觉、普通编码器和spin世界航向不能混用。
- 连续角度仅在相邻有效反馈位移确定小于半圈时可恢复。反馈过期/位移存在歧义时停止输出，
  不凭猜测补圈；恢复沿用反馈稳定、重新对齐与现有解锁规则，不追赶失联期间的旧目标。

## 提前制动

- 在外环P到速度内环之间增加有速度、加速度约束的目标规划，减少大速度阶跃。
- 以度为内部规划单位，速度使用RPM时必须先乘6：
  d_stop_deg = (6*rpm)^2/(2*brake_accel_deg_s2) + abs(6*rpm)*latency_s + margin_deg。
  brake_accel须在已稳定的低速内环、当前负载和电流限下实测并降额；不能凭空设为能实现的制动能力。
- 接近固定目标时将允许速度约束到sqrt(2*a*abs(error_deg))/6 RPM，并考虑上述延迟/裕量。
  此包络依赖速度内环实际跟踪，不能单独作为停车保证。
- 剩余距离不足、越过目标或正在背离目标时进入制动状态，暂以零转速为目标，
  保留位置目标；稳定低速后再慢速返回。状态转换加滞回，正常加速斜坡不得拖延必要制动。
  零转速目标不等于零电流；由速度闭环产生与转动方向相反的制动力矩。
- 制动/超速保护每次内环调用检查，不能只等每五次的外环。反馈/遥控失联时仍走原有零输出联锁，
  不使用过期速度做主动制动。异常持续超速/跟踪失败锁定退出控制，不允许无限重试转圈。

## PID处理

- 独立速度环验证时绕过位置环，以受限±5 RPM与0 RPM目标检查启动、跟踪、停车。
  Ki=Kd=0并清历史，先逐步调P；旧Ku=5.5测量时外环开着，不能用于速度内环ZN。
  小P低速不动时检查输出/阻力与P，不靠大积分积蓄起动能量；不提高现有协议电流限。
- 内环稳定后再引入有限I，外环先用P。位置P候选0.02 RPM/编码器刻度，输出统一限10 RPM，
  待速度内环验证后再试；不是已验证参数。外环I/D初始为0。
- 抗饱和以有效输出限min(配置限,协议5460)判断。仅阻止继续推向饱和方向的积分，
  允许误差反向时退出饱和；有额外输出约束时使用实际受限输出回算积分。
- 本次未采到5460饱和，因此仅修抗饱和不够：制动状态禁止增加旧方向积分，并通过有界衰减
  消退抵消制动的积分。接近目标、速度误差较小且未受限时再正常积累，保留静态负载补偿。
  不在每次误差换号时粗暴清零，也不在每次回中调用完整PID_Reset。
- D先关闭以隔离观测到的尖峰。若P/PI仍需要D，再用同步速度记录选择测量滤波/小D。
  启用或重置D时以当前实际测量初始化历史，避免last_measure=0引起瞬变。

## 实现边界与验证

- 配置放机器人配置，yaw状态机与坐标放application/gimbal；通用轨迹/抗饱和算法放modules，
  不把电机ID、CAN协议或具体角色塞进通用PID。保持现有依赖方向、冻结底层及CAN电流协议。
- 第一阶段允许现有约4/20 ms周期，所有积分/斜坡按真实dt；单独累计周期异常与最坏耗时，
  不把增加延时或五次分频当作实现1 kHz/200 Hz。超时按明确故障策略退出，不补算大步目标。
- 主机验证：相同持续时间不同dt目标一致、回中不提速且目标固定、8191→0连续、超半圈不换圈追赶、
  模式切换/失联重入无突跳、制动与积分退出行为、协议限幅一致。再做双车型构建及现有回归。
- 上板依次验证独立速度环±5→0 RPM、位置±5°/±10°、短推杆回中及模式切换；接内环前不得宣称
  已可实现制动包络。验收重点是回中不提速、不连续转圈、速度收敛、目标固定与联锁有效。
- 4555前向零点不等于机械限位；允许转角/线束绕转范围尚未确认，方案不新增猜测的机械限位。
