# GM6020 控制模式

2026-09-08 用户重新调整 yaw 电机固件，确认其已改回电压模式。
当前 `infantry_standard` 的 yaw 和 pitch 都使用电压指令。
软件不会修改电机内保存的控制模式；支持电流环选项的电机应关闭该选项以匹配本配置。

| 轴 | 总线 / 硬件 ID | 反馈 | 控制报文 / 槽位 | 当前输出上限 |
|---|---|---|---|---|
| yaw | CAN1 / 5 | `0x209` | `0x2FF` / 0 | ±25000 电压指令刻度 |
| pitch | CAN2 / 4 | `0x208` | `0x1FF` / 3 | ±25000 电压指令刻度 |

依据 [DJI GM6020 使用说明 v1.4（2023.10），第 5–7 页](https://rm-static.djicdn.com/tem/17348/RoboMaster%20GM6020%E7%9B%B4%E6%B5%81%E6%97%A0%E5%88%B7%E7%94%B5%E6%9C%BA%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E20231013.pdf)：
电流报文为 `0x1FE/0x2FE`，±16384 对应 ±3 A；电压报文为 `0x1FF/0x2FF`，
量程为 ±25000。橙灯常亮表示电流模式收到电压指令。旧 v1.2 手册没有这项定义。

`config/robots/infantry_standard.c` 显式设置 yaw 的 `protocol.dji.gm6020_mode`
与 `command_limit`。零初始化模式表示电压，因此 pitch 和哨兵配置继续沿用原协议。
模式、反馈 ID、发送 ID 或槽位不匹配时拒绝发送。应用、适配器和 CAN 发送边界均限幅。
`CommandCurrent` 等旧接口名称保留，但输入是所选协议的原始刻度，并非统一的安培值。

yaw 继续使用位置→速度→电压的串级闭环，恢复提交8911563的电压模式增益：
位置环 P=1.5、I=0.03、D=0，上限600 RPM、积分上限450；速度环
P=52.5、I=0.12、D=1.8、积分上限6000，输出上限从旧30000修正为协议允许的25000。
应用仍保留手动300 RPM、保持/自瞄500 RPM的进一步限速。上述是恢复已有电压参数，
不是新电机固件下已完成的实车调优。pitch仍使用其原角度闭环与重力补偿，没有复制到yaw。

两轴都是电压模式不等于发送同一ID：yaw硬件ID5使用2FF的槽0，pitch硬件ID4使用1FF
的槽3。底盘CAN1 ID1–4发送200，与yaw的2FF独立。通用1FE/2FE电流模式支持及其
主机测试仍保留，但本车型yaw不会向这些组发送。

保留既有遥控离线停机和两轴上电位置检查。下载后仍按本机配置不自动复位运行。
用户在准备好测试后复位，检查 CAN1 是否持续收到 `0x209`、发送 `0x2FF`，以及橙灯
是否解除。若 pitch 不在配置启动范围内，两轴仍保持零输出。
