# GM6020 控制模式

2026-09-09 用户开启 CAN1/ID5 电流环；零电流通信测试后，要求采用参考库的 yaw PID。
当前 `infantry_standard` 的 yaw 使用电流指令，pitch 继续使用电压指令。
软件不会修改电机内保存的模式；当前 yaw 要求开启电流环，pitch 使用电压模式。
2026-09-10纯Flash读回已确认板上包含yaw PID、关闭pitch限位及底盘双环
（bin SHA256前缀ccaca1a8，ELF前缀4d440c8a）；本次助手未烧录。

| 轴 | 总线 / 硬件 ID | 反馈 | 控制报文 / 槽位 | 当前输出上限 |
|---|---|---|---|---|
| yaw | CAN1 / 5 | `0x209` | `0x2FE` / 0 | ±546 电流刻度（约 ±0.1 A） |
| pitch | CAN2 / 4 | `0x208` | `0x1FF` / 3 | ±25000 电压指令刻度 |

依据 [DJI GM6020 使用说明 v1.4（2023.10），第 5–7 页](https://rm-static.djicdn.com/tem/17348/RoboMaster%20GM6020%E7%9B%B4%E6%B5%81%E6%97%A0%E5%88%B7%E7%94%B5%E6%9C%BA%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E20231013.pdf)：
电流报文为 `0x1FE/0x2FE`，±16384 对应 ±3 A；电压报文为 `0x1FF/0x2FF`，
量程为 ±25000。橙灯常亮表示电流模式收到电压指令。旧 v1.2 手册没有这项定义。

`config/robots/infantry_standard.c` 显式设置 yaw 的 `protocol.dji.gm6020_mode`
与 `command_limit`。零初始化模式表示电压，因此 pitch 和哨兵配置继续沿用原协议。
模式、反馈 ID、发送 ID 或槽位不匹配时拒绝发送。应用、适配器和 CAN 发送边界均限幅。
`CommandCurrent` 等旧接口名称保留，但输入是所选协议的原始刻度，并非统一的安培值。

yaw PID 来源为 [nyush-rm-control 步兵配置，提交 2b7ca720](https://github.com/NYUSH-Robotics-Club/nyush-rm-control/blob/2b7ca720e856f1efda9f6de6259faea42654720d/application/robot_configs/robot_infantry.h#L134-L144)。
按用户要求采用角度环 P/I/D=28/0/1.3、速度环=150/135/0，换算到本库编码器刻度/RPM：

| 配置 | P | I | D | 输出限幅 | 积分限幅 |
|---|---|---|---|---|---|
| 本库位置环 | 0.205078125 | 0 | 约0.009521484 | 2200/6 RPM | 100/6 RPM |
| 本库速度环 | 900 | 810 | 0 | 546电流刻度 | 546电流刻度 |

换算关系：位置环增益乘 `(360/8192)/6`，速度环增益乘 `6`，因为1 RPM=6°/s。
这只换算输入/速度输出单位，不代表电压与电流控制的出力等价。原26000电压限幅不用于
电流模式，原4000积分上限收紧到546，避免小电流初调积累过大的积分。
保留本库反馈来源、死区、PID滤波、手动300 RPM限速及联锁；未移植参考库的速度前馈。
pitch 仍使用其原角度闭环与重力补偿。该配置是待实测的电流初调参数。

`CC=gcc sh tests/host/run_tests.sh` 与 `source tools/activate.sh && just build` 通过。
主机测试覆盖单位换算、实际云台回调的正负非零输出/限幅，以及仅yaw反馈过期时双轴归零。
最新只读采样已收到yaw RX209；pitch角度5398–5399超旧1000–4000范围，导致双轴启动保护。
历史上用户确认电机重装，曾暂时关闭pitch限位。09-11完成三点测量后已按用户要求删除
停用开关及绕过分支，恢复原有启动范围检查和目标裁剪：最高1566、最低2205，启动及
重新对齐目标1971（均为绝对编码刻度）。目标限位不能保证实际运动无惯性超调。
角度换算仍使用一圈8192刻度并保留失联停机；重力/耦合参数此次未调整，仍待实车核定。
09-10恢复后有效采样确认startup持续1；主机测试覆盖5398启动、跨零、恢复限位与失联停机。
非零TX2FE及接近指令值的反馈电流已采到：yaw输出持续饱和±546（约0.1A），大角度误差
下转速多为0，当前应核定电流限幅并检查机械负载；不是继续放大PID。尚未提高限幅。

yaw 硬件 ID5 使用 2FE 的槽0，pitch 硬件 ID4 使用 1FF 的槽3。
底盘 CAN1 ID1–4 发送 200，与 yaw 的 2FE 独立；整车双 CAN 输出联锁继续保留。

- 官方 v1.4 手册第 6 页明确：APP >=1.0.11.2 配合 Assistant >=2.7，开启电流环
  开关后支持转矩电流控制；该版本手册仍保留电压协议，不能把升级等同于强制电流模式。
  用户此前关闭、随后重新开启了电流环；最新配置以此次开启状态为准。
- [官方 v1.2 手册（2020.05）](https://rm-static.djicdn.com/tem/17348/RoboMaster%20GM6020%E7%9B%B4%E6%B5%81%E6%97%A0%E5%88%B7%E7%94%B5%E6%9C%BA%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E.pdf)
