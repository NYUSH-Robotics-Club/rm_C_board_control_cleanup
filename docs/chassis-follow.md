# 步兵云台方向平移跟随

左拨杆中档（`rc.s[1] == RC_SW_MID`）时，左摇杆前后、左右以云台朝向为参考。
旋转通道仍控制底盘转速，不自动把底盘车头转向云台。下档普通模式、上档小陀螺和
哨兵原有路由保持；本次标定不应用于这些模式。

## 安装标定与解算

`config/robots/infantry_standard.c` 的 `s_chassis_follow` 保存：

- `yaw_forward_ticks = 4555`：用户确认云台朝底盘正前方的单圈绝对编码。
- `yaw_ccw_sign = 1`：暂按编码增大为俯视逆时针（左转），**尚未实车确认**。
  若手动向左转时编码减小，改为 `-1`。它独立于电机电流方向与PID参数。

命令应用通过电机服务按 yaw 角色取实际反馈；DJI GM6020 的 `MotorSnapshot.position`
来自 `angle_raw`，单位为0～8191单圈刻度。不是IMU世界航向，也不是云台目标位置。
相邻两次读取跨零不影响朝向换算，不需要记录累计转过的圈数。

```text
theta = yaw_ccw_sign * wrap_to_half_turn(raw - 4555) * 2*pi / 8192
vx_body = cos(theta) * vx_stick - sin(theta) * vy_stick
vy_body = sin(theta) * vx_stick + cos(theta) * vy_stick
```

保留现有遥控归一化 `vx_stick=-ch[3]/660`、`vy_stick=ch[2]/660`，死区3；
车体坐标为+x前、+y左。现有全向轮运动学再将平移向量投影到四个轮子的驱动方向，
乘轮径/减速比换算RPM，并用公共缩放限速保持方向。四轮几何和安装方向未修改。

按暂定的 `yaw_ccw_sign=+1`，前推对应：

| yaw编码 | 相对朝向 | 底盘平移方向 |
|---|---|---|
| 4555 | 0° | 向前 |
| 6603 | +90° | 向左 |
| 2507 | −90° | 向右 |
| 459 | 180° | 向后 |

## 反馈失效与验证

标定非法、yaw角色不唯一、不是支持的DJI GM6020、反馈未初始化/无效、编码越界，
或实际反馈超过20ms未更新，中档底盘命令禁用、三轴归零；不退回另一坐标系运动。
后续有效新反馈允许恢复。原有遥控失联、CAN解锁及四轮反馈联锁继续生效。
命令归零不等于机械瞬间停稳。

测试覆盖真实命令回调的4555标定、±90°/180°、8191→0、方向反转、反馈过期及错误拒绝；
并将路由与当前步兵全向轮运动学组合，在−180°至+180°每5°反算轮速对应的平移方向。
数学验证不证明实车四轮安装方向正确；还需核对左转编码符号及前推遥控实际方向。
本次保持yaw速度环调试开关，不恢复位置外环；未烧录或主动驱动实机。
